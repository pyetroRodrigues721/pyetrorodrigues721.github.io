如何挂载一个新页面

这个站点有一套挂载框架：往 pages/ 文件夹丢一个带 front matter 的 HTML，提交时自动构建，页面就被挂到全站——归档、领域计数、最近更新、筛选器、站点地图全部自动收录，首页一行都不用改。

三步

  1. 复制模板：cp pages/_template.njk pages/my-post.html
  2. 改 front matter，正文只写片段（不要写 <html>/<body>，页面外壳由框架注入）
  3. git add + git commit —— 提交钩子自动构建挂载，无需手动跑命令

发布后地址是 /my-post/。删除源文件再提交，页面会自动下架。

front matter 字段

字段必填说明
title是归档标题
desc是一句说明，显示在归档与分享卡片
field是领域 id：web / design / tools / lab / books / life / photo
type是w=我写的 · p=我做的 · t=我试的 · c=对话
published是YYYY.MM（不能叫 date，那是 Eleventy 的保留键）
og_image否分享卡片配图，如 /og.png

提交时自动发生什么

  • 校验 front matter：领域 id、类型、日期格式不合法会拦住这次提交
  • 构建页面外壳：导航、页脚、夜读模式、SEO 标签自动注入
  • 生成 mounted.js 与 sitemap.xml 并一并暂存
  • 检测孤儿输出：源文件删了但输出还在 → 自动下架

正文里的 {{ 和 {% 会原样输出，写代码示例不用转义。

克隆之后

如果提交时提示找不到 eleventy，先跑一次 npm install——它会顺手把提交钩子接上（core.hooksPath）。
