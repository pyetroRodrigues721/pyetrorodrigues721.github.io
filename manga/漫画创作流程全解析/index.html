01

全景工作流：从一句话到一本成书

漫画不是"画得好"就够了，它是一条工序链。每道工序解决一类问题，上一道偷的懒，下一道都会加倍还回来。下方的条形代表该阶段在整部作品中所占的精力比重。

02

阶段详解：每道工序的产出物、组件与短板

短板是最值钱的信息。知道自己缺什么，才知道该去哪里补。

01

策划 · 剧本STORY

目标：把"想画点什么"变成一条能被别人读懂、并且自己能画完的故事线。

关键动作

  • 一句话梗概（Logline）：主角 + 欲望 + 阻碍 + 代价
  • 三幕式或起承转合结构，标出每幕的情绪拐点
  • 分话大纲：每话末尾必须有一个翻页/下滑的钩子
  • 文字台本：写清每格发生什么、说什么、留什么白

需要的基础组件

故事模板人物小传表 世界观设定集冲突/动机清单 节奏曲线图对白风格样本
常见短板：想法很多，结构很散

新手最常卡在"第二话崩盘"——开局热情撑得住，中段失去张力。解法是先用别人的分镜书和拉片素材拆结构，而不是硬写。

02

人设 · 世界观DESIGN

目标：让角色在任何一格里都能被认出来，并且有"演戏"的余地。

关键动作

  • 三视图 + 表情集 + 常用姿势集，锁定轮廓特征（剪影可辨识）
  • 服装道具拆解：哪些要画细，哪些可以简化
  • 配色板与光源设定：白天/夜景/室内的光比统一
  • 场景地图：故事发生的空间关系先画出来

需要的基础组件

人体比例模板表情表 服装参考板道具图鉴 色彩脚本场景平面图
常见短板：人体结构与透视

这是最普遍、也最容易用素材补齐的一环。3D 人偶摆姿势 + 解剖模型对着看，比闭门苦画效率高一个数量级。

PoseManiacs 3D 肌肉 DesignDoll 人偶 Magic Poser Sketchfab 3D
03

分镜 · ネームNAME

目标：决定读者看什么、怎么看、在哪一页被击中。整部作品的节奏在这一阶段定型。

关键动作

  • 页面结构：每页几格、视线动线、翻页冲击点放在右下
  • 镜头语言：远景交代 / 中景关系 / 特写情绪，按需切换
  • 信息密度控制：一格只讲一件事，重要格子放大
  • 气泡位置预留：别让文字压住脸和手

需要的基础组件

分镜草稿本构图参考库 镜头词汇表原稿纸模板 翻页钩子清单情绪曲线图
常见短板：构图缺乏电影感

最快的补法是"拉片"——用电影截帧库研究景深、机位、正反打、留白。每周拆 20 张分镜，比画 20 张更有用。

04

草稿 · 线稿INK

目标：把分镜放大成干净、有体积、有情绪的线条。线是漫画的语言。

关键动作

  • 放大草稿：确定人体、透视、光影三大关系
  • 勾线：外轮廓粗、内结构细，转折处提笔留气口
  • 线重分层：主线 / 结构线 / 氛围线，情绪随之变化
  • 擦除与整理：保持画面呼吸，别把线填死

需要的基础组件

笔刷套装笔压曲线预设 人体姿势图库手部/足部专项 头发/衣褶画法透视尺/辅助线
常见短板：线条抖、动态僵

先用限时速写把"抓形"练出来（30 秒/1 分钟动态），再练勾线。姿势图库和速写计时器是这一环节的最佳组合。

Line of Action QuickPoses Proko 人体课 CSP ASSETS 笔刷
05

背景 · 网点 · 上色TONAL

目标：给画面加上灰度与空间，让黑白也读得出空气、光和距离。

关键动作

  • 背景：可用 3D 模型打底 + 线稿化，省下大量透视时间
  • 网点：灰阶分层（高光/中间调/暗部/最暗），控制画面灰度平衡
  • 上色（条漫/彩漫）：固有色 → 光影二分 → 环境色 → 氛围滤镜
  • 特效：速度线、集中线、光晕、噪点，统一风格

需要的基础组件

网点/纹理包PBR 材质贴图 HDRI 环境光3D 场景模型 照片参考库色彩脚本 笔刷特效
常见短板：灰度脏、空间糊

背景不必全手绘。CC0 贴图库 + HDRI 打光 + 3D 模型打底，是职业条漫工作室的常规操作，能省下 40% 以上的时间。

Poly Haven ambientCG Unsplash True Grit Texture
06

文字 · 拟声词 · 后期TYPE

目标：让文字成为画面的一部分，并把作品送到读者手上。

关键动作

  • 对白排版：气泡形状、字号、行距表达语气与音量
  • 拟声词设计：字形本身就是演出，日系手写体是利器
  • 旁白框与叙事声音：统一视觉语言
  • 输出：原稿纸出血、分辨率（印刷 600dpi 线稿 / 网屏）、格式规范
  • 发布：平台投稿规范、单行本排版、宣传图

需要的基础组件

标题/正文/拟声词字体气泡素材 效果字库原稿纸模板 输出参数表封面排版参考
常见短板：字体侵权与排版违和

商用务必使用明确标注"可免费商用"的字体。日系拟声词和中文卡通体各有成熟免费库，别用系统默认黑体糊弄。

05

四周补基计划：把素材变成能力

素材只是拐杖。真正的补齐方式是"用素材去练"，而不是囤素材。以下是一个可执行的最小路径。

WEEK 01

抓形与人体

  1. 每天 20 分钟限时速写（30s→1min→5min）
  2. 用 3D 人偶摆 3 个叙事姿势并描摹
  3. 临摹 10 张手部/足部专项
  4. 建立自己的"姿势参考"收藏夹
WEEK 02

构图与分镜

  1. 每周拆解 20 张电影分镜截帧
  2. 把一段小说改写成 4 页分镜
  3. 练习翻页钩子：每页末格留悬念
  4. 研究气泡与视线动线的配合
WEEK 03

线稿与灰度

  1. 选 3 套笔刷，固定下来别再换
  2. 练习线重变化：外粗内细
  3. 用网点做 5 张灰度层次练习
  4. 3D 打底 + 勾线，完成 2 张带背景的整页
WEEK 04

完稿与输出

  1. 搭好自己的字体库与气泡样式
  2. 走完一次完整流程：8 页短篇
  3. 按平台规范导出并做打印测试
  4. 复盘：哪道工序最耗时，就补哪块

素材可以补齐工具，
但分镜与故事只能靠一遍遍画。
