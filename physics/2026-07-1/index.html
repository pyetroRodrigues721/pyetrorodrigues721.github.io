每个阶段只有一个量保持不变：① C 不变（充电），② Q 不变（断开拉开），③ C 又不变（放电）。

ERROR ANALYSIS
SPOT THE TRAPS

这道题最容易犯哪些错误？

两个高频陷阱
ERROR 01守恒量判错（B）
S 接 b 后电容器孤立，电荷无处可去，守恒的是 Q 而不是 U。② 应为水平段（U 增大）；B 画成竖直段（U 不变、Q 变），错。
ERROR 02图线形状与走向错（C / D）
U–C 图中 ② 是双曲线一支 U = Q/C：C 减小时 U 应上升。C 的走向画反，D 把双曲线画成直线，均错。
学霸笔记
遇到“电容器图像”类问题，默念口诀：
先定守恒量，再定图线形；
斜率是电容，反比是双曲线。
两条常识先行：断开（S 接 b）则 Q 恒定，接电源则 U 恒定；平行板电容 C ∝ S/d，d 增大 C 减小。
