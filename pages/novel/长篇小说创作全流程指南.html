01
WORKFLOW

六大阶段工作流
从种子到面世的完整链路

每个阶段都有明确的任务和必须落地的产出物。产出物没做出来，就不算过这一步——这是防止长篇中途崩盘的唯一硬性纪律。

PHASE 01

孕育期 · 找到那颗种子

约 1–2 周

先把「为什么写」想清楚。一句话讲不清的故事，二十万字只会更讲不清。

1.1核心创意 Premise

一句话包含人物 + 困境 + 张力。写不出这一句，先别动笔。

1.2主题 Theme

全书真正追问的问题。主题是长篇唯一的锚，散了就靠它收。

1.3类型与读者定位

题材、目标读者、阅读场景、对标作品清单（至少列 3 部）。

1.4体量与终点

预计字数、结局大方向。先定终点，才能倒推路径。

产出物 一句话故事主题陈述对标书单结局雏形
PHASE 02

准备期 · 搭建世界与人物

约 2–6 周

设定服务于冲突：用不上的设定进资料库，别塞进正文。这一步也是「专业知识缺口」集中暴露的地方。

2.1世界观设定

时代、地理、社会结构、行业规则、力量体系。现实题材同样需要。

2.2主角三件套

欲望（要什么）+ 缺陷（缺什么）+ 弧光（如何改变）。

2.3对手与配角

反派要有自洽逻辑；配角一人一个记忆点。

2.4专业知识考证

医、法、军、商、史……到第 03 部分按缺口补课，避免硬伤。

产出物 设定集人物小传 ×N关系图考证笔记
PHASE 03

细化期 · 设计骨架

约 2–4 周

长篇最危险的翻车点：埋了伏笔忘了收、支线越写越散、中期塌陷。全部在这一步预防。

3.1选择结构

三幕式 / 起承转合 / 英雄之旅。可以打破，但要知道自己打破的是什么。

3.2三级大纲

粗纲（全书起承转合）→ 章纲（每章推进什么）→ 细纲（场景走向）。

3.3伏笔与线索表

埋设位置 → 回收位置 → 状态。全程滚动更新。

3.4多线时间线

主/支/暗线交错时，单独建时间线文档防止穿帮。

产出物 粗纲 + 章纲 + 细纲伏笔追踪表时间线节奏曲线
PHASE 04

创作期 · 把字写出来

3 个月 – 2 年+

长篇是体力活，靠流程与习惯，不靠灵感。先写后改，是进度停滞的头号解药。

4.1强开局

开头 1–3 章反复重写：抓注意力、立世界观、抛核心悬念。

4.2日常节奏

固定时间 + 固定字数（日 2000–3000）。写完留「起笔提示」给明天。

4.3结构巡查

每 10–15 万字设一个中型高潮；每 5 万字回看大纲查偏航。

4.4状态维护

卡文先跳写；松紧交替；用写作社群互相监督。

产出物 初稿全本写作日志章节数据库
PHASE 05

修稿期 · 好文章是改出来的

约 1–3 个月

先冷却一到两周，消灭「作者盲区」。修改必须分层，绝不混着改。

5.1结构层

情节完整吗？支线冗余吗？高潮够高吗？大刀阔斧删。

5.2人物 + 逻辑层

行为符合动机？弧光完成？前后矛盾？伏笔全收？

5.3场景 + 文字层

场景必须推进情节或揭示人物，否则删；再修对话与节奏。

5.4外部反馈

找 2–3 位目标读者通读，关注他们在哪里走神、在哪里困惑。

产出物 二稿 / 三稿读者反馈报告校对稿
PHASE 06

面世期 · 让它到达读者

持续进行

书名、简介、封面是你的「第一产品」。但作品本身，永远排第一位。

6.1网文路线

选平台 → 研究调性与签约规则 → 稳定更新 → 与编辑沟通。

6.2出版路线

定稿 → 投稿出版社/期刊或找经纪人 → 签约 → 三审三校 → 上市。

6.3自出版路线

电子书平台、众筹出版、独立发行；自己负责排版与封面。

6.4长期运营

建立与读者的连接、维护作品资料、规划系列与下一步。

产出物 投稿包书名 + 简介 + 封面更新计划
02
ASSET LIBRARY

基础材料组件库
十二份必须维护的文档

长篇的稳定，取决于这些文档的滚动更新。它们既是写作时的速查表，也是防止设定穿帮、伏笔遗失的保险丝。

A-01

一句话故事卡

全书的压缩锚点，任何时候都能快速对齐方向。
  • 主角身份
  • 核心困境
  • 关键行动
  • 赌注与张力
PHASE 01 建立 · 全程引用
A-02

主题陈述表

把模糊的“想表达什么”变成可操作的判断标准。
  • 核心问题
  • 正/反观点
  • 通过哪条人物线呈现
  • 结尾立场
PHASE 01 建立 · 修改期校验
A-03

世界观设定集

唯一的“官方真相”，所有设定以此为准，实时更新。
  • 时代 / 地理 / 社会结构
  • 规则体系（力量、行业、制度）
  • 禁忌与边界
  • 未采用设定存档
PHASE 02 建立 · 滚动更新
A-04

人物小传卡

写对话和行为前先查卡，保证言行一致。
  • 姓名 / 年龄 / 外貌 / 口癖
  • 成长史与关键创伤
  • 欲望 · 恐惧 · 价值观
  • 弧光起点与终点
PHASE 02 建立 · 全程引用
A-05

人物关系图

关系一多就乱，图比记忆可靠。
  • 联盟 / 对立 / 血缘 / 情感
  • 关系变化节点
  • 隐藏关系标注
  • 每章推进的关系事件
PHASE 02 建立 · 滚动更新
A-06

三级大纲

粗纲定骨架、章纲定推进、细纲定场景。
  • 粗纲：起承转合与大高潮位置
  • 章纲：每章一句话 + 悬念收尾
  • 细纲：场景清单与关键对话走向
  • 留弹性，不锁死
PHASE 03 建立 · 创作期执行
A-07

伏笔追踪表

长篇第一杀手是“埋了不收”，这张表是唯一解药。
  • 伏笔内容
  • 埋设章节
  • 计划回收章节
  • 状态：未埋 / 已埋 / 已收 / 已废弃
PHASE 03 建立 · 每周核对
A-08

时间线文档

跨度大、多线叙事时防止时间穿帮。
  • 全局纪年 / 季节
  • 各线并行节点
  • 角色年龄推算
  • 与历史事件的对应
PHASE 03 建立 · 滚动更新
A-09

章节数据库

写到第八十万字还能秒查“那把刀是哪来的”。
  • 章节摘要
  • 出场人物
  • 新出现设定 / 物件
  • 字数与状态
PHASE 04 建立 · 每章更新
A-10

风格与文字规范

统一叙事腔调、称谓、数字与专有名词写法。
  • 叙述视角与时态
  • 人名 / 地名 / 专有名词表
  • 禁用词与偏好句式
  • 对话标点规范
PHASE 03 建立 · 校对期执行
A-11

素材与考证笔记

专业知识的“外挂硬盘”，写到哪查到哪，注明出处。
  • 按领域分类的摘录
  • 来源链接与书目
  • 可化用的真实细节
  • 存疑待核清单
PHASE 02 起 · 全程积累
A-12

灵感与弃稿库

好点子不会消失，只是暂时用不上。
  • 碎片灵感速记
  • 被删场景与理由
  • 备用转折方案
  • 下一部书的种子

CHECKLIST

验收清单
点开勾选，看见进度

写长篇最怕“感觉写了很多，但不知道完成到哪”。用这两张清单给每个阶段打勾——勾不完，不进下一阶段。

开工前 · 立项自检

BEFORE YOU WRITE
一句话能讲清故事：人物 + 困境 + 张力
主题写成一个明确的问题，并有初步立场
读过至少 3 部同类型对标作品并做过拆解
结局大方向已定（可以改，但不能没有）
主要人物小传写完，动机与缺陷清晰
世界观设定集建立，且每条设定对应冲突
专业知识缺口列成清单，逐项找到靠谱来源
粗纲完成：起承转合与三个大高潮位置明确
章纲至少覆盖前 30 章
伏笔追踪表建立（哪怕只有三行）

完稿后 · 交付自检

BEFORE YOU SUBMIT
冷却两周以上再通读第一遍
结构层：支线已删冗，高潮高于前文
人物层：每个关键行为都能对应动机
伏笔表全部状态为「已收」或「明确废弃」
时间线与设定集交叉核对，无穿帮
专业知识硬伤请至少 1 位内行过目
至少 2 位目标读者反馈已回收并处理
开篇三章单独打磨过 3 遍以上
书名、简介、封面按「第一产品」标准打磨
错别字与标点完成一轮机械校对
构思定方向 → 设定搭舞台 → 大纲建骨架
习惯成正文 → 分层改到死 → 送达读者。
